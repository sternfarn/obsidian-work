## Block info

- `text`: valider html-inhalt
- html-phrasingblocks -> html inhalt als würde er in einem `<p>` stehen:
	- `phrasing-text`
	- `blockquote`
	- `photoblock`
	- `graphicblock`
- `rawHTML`: invalides html (kommt nicht wirklich vor)
- `textualdata`: jsons, kein standardschema
- `tabellen`: offline
